# 训练会话报告：怎么生成、怎么打开、怎么讲

对应「5 件事」里的第 4 件。一句话：**每跑一次训练，结束时会自动生成一页报告，点顶部的「导出报告」就能看，也能存成 PDF 交给评委。**

## 一、报告从哪来（不用你操作）

链路是这样走的，全是自动的：

1. 脑电服务每算完一个窗口，就往桥接发一条状态
2. 桥接收到一条，就往 `sessions/session-日期-时间.jsonl` 追加一行
3. 脑电服务断开（或者你点「停止」），桥接把这次会话收尾，压成一页
   `sessions/report-日期-时间.html`

两个文件都在：

```
/Users/chujingyue/DeepWorks/NeuroBloom/sessions/
```

报告是单文件 HTML：不联外网、不带脚本、图片都是内联 SVG，拷给别人也能打开。

## 二、怎么看（三种方式，任选）

1. **控制台顶部「导出报告」按钮**，新开一个标签页直接看
   （它读的是 `http://127.0.0.1:8765/report`，永远给你最新那一份）
2. 收藏这个地址，想直接下载就加 `?download=1`：
   `http://127.0.0.1:8765/report?download=1`
3. 自己去 `sessions/` 文件夹双击 `report-*.html`

还没有跑过训练时，地址会回一句「还没有训练记录」，不会报错。

## 三、想存 PDF / 打印

浏览器里 `Cmd + P` → 目标选「另存为 PDF」。
报告已经写了打印样式：打印时去掉灰色底和阴影，白纸黑字，A4 一页到两页。

## 四、报告里有哪些数（白话版）

| 位置 | 是什么 | 怎么用 |
|---|---|---|
| 顶部四个大数 | 放松态占比、平均放松度、左右不对称均值、信号有效占比 | 一眼看这次训练成不成 |
| 放松度走势 | 一条曲线，0 到 1 | 掉下来的地方通常对应动作、说话、电极松了 |
| 两条轴 | 放松度（α/β）和专注度（β/θ）分开列 | 证明「放松」和「专注」是两个方向，不是一个数 |
| 左右半球对称性 | 一条曲线 + 前半段/后半段的对比 | 这是我们的护城河，能看出训练过程中对称性有没有改善 |
| 频带构成 | δ θ α β γ 各自的功率和占比 | 占比比绝对值稳，适合跨次对比 |
| 信号质量与引导 | 合格电极数、无效帧数、这次说过哪些引导语 | 证明引导语是按状态生成的，不是随机播的 |

## 五、手动重出一份（改了报告样式时用）

```bash
cd /Users/chujingyue/DeepWorks/NeuroBloom
.venv/bin/python -m analysis.session_report --in sessions/session-20261021-143000.jsonl
# 想指定输出位置
.venv/bin/python -m analysis.session_report --in xxx.jsonl --out /tmp/report.html
```

命令会顺手在终端打印这次的关键数（时长、判定帧、有效占比、放松度均值、不对称均值）。

## 六、边界（必须说清楚，别被问倒）

- 报告是**过程记录**，不是诊断书。页脚已经写了「不构成医学诊断或治疗建议」，答辩时也照这个口径讲。
- 「左右半球对称性」是**同一时刻左右两侧 α 功率差**，不是医学上的「脑区激活」。我们只讲「训练过程中这个差距怎么变」，不讲「你哪半球坏了」。
- 一次训练 = 脑电服务启动到断开这一段。中间断了超过 2 分钟，会自动切成两段，各出一份报告。
- 合成板（演示）跑出来的报告同样会生成，但里面的数值是合成的。给评委看报告时，最好说明这是哪一次、是不是真机。

## 七、答辩可以这么说

> 每次训练结束系统会自动留一份报告，里面有这一次的放松度走势、左右半球不对称指数的变化、以及当时系统实际说过的引导语。设计目的是让康复师能在两次训练之间做对比，而不是只凭一次感觉。

## 八、还没做的（诚实清单）

- 报告只在会话结束时生成一份快照，不能中途刷新看到「进行中的统计」
- 没有历史报告的列表页，也没有跨次训练的对比曲线
- Unity 那边的画面参数（阳光/雾/花开/水晶）目前没进报告，只在会话记录里有原始值
