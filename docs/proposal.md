# Project Proposal — 脑境 NeuroBloom

> 版本 v1.0 · 2026-11-12 · 对应课程 Project-based Course 1105
> 关联：[MVP PRD](prd.md) · [技术设计](tech-design.md) · [验证结果](verification.md)

## 1. 问题（Problem）

卒中患者出院后进入居家康复期，肢体功能有明确的训练动作和评价量表，**情绪与注意力却没有可日常观察的指标**。治疗师按工时排班，无法上门；家属能看见的是"走得好不好"，看不见"是不是越来越沉、越来越散"。等到复诊时才发现状态下滑，通常已经错过干预窗口。

这个问题有三个可直接观察的表现：

- 院内评估带不回家里，居家阶段没有连续记录；
- 没有人在旁边盯着，训练难以坚持；
- 情绪与注意力的变化缺少客观参照，只能靠回忆描述。

## 2. 用户（Users）

| 角色 | 场景 | 需要什么 |
| --- | --- | --- |
| 卒中后居家患者（轻中度，能独立坐 20 分钟） | 每天在家做 15 分钟训练 | 不用看懂数字，也知道自己现在紧不紧 |
| 康复治疗师 / 社区治疗师 | 同时管理多名居家患者 | 远程看到训练是否发生、状态趋势如何 |
| 家属 | 日常照护 | 一个能看懂的状态提示，而不是一堆波形 |

## 3. 证据（Evidence）

**先说清楚本阶段有什么、没有什么。**

| 类型 | 状态 | 说明 |
| --- | --- | --- |
| 公开文献 | 已查阅 | 脑电 α 节律与放松状态的关系、额区不对称与情绪的研究均有较成熟文献；居家康复依从性在不同研究报告间的跨度很大，说明"能否坚持"本身就是问题 |
| 团队流程观察 | 已具备 | 项目期间与康复场景相关的课程材料、设备说明书、治疗师端流程梳理 |
| 正式用户访谈 | **未开展** | 本阶段没有伦理批件与入组渠道，**未做患者或治疗师访谈** |
| 可用性测试 | 计划中 | 见 [验证方案](验证方案.md) 的 L3 层 |

因此，下面两条在本阶段属于**假设**，不作为已证实的结论使用：

- **A1**：居家患者愿意每天花 15 分钟戴帽训练。（验证方式：5 名健康成人连续 5 天的完成率，以及 3–5 名治疗师访谈）
- **A2**：治疗师愿意用一张趋势图替代部分电话随访。（验证方式：治疗师访谈 + 任务走查）

> 课程要求不得编造访谈引文与用户数量。本文件不含任何虚构引述；A1/A2 明确标为假设，并在 PRD 的开放问题中保留。

## 4. 方案（Solution）

一条从采集到反馈再到记录的闭环：

```
脑电帽（16 通道） → 一人一基线判定 → 三维花园实时反馈 → 治疗师控制台 → 报告与随访趋势
```

关键设计取舍：**不给患者看数字**。α/β 的绝对值因人而异，同一个人不同时段实测能差 3 倍，绝对值没有可比性。系统只做一件事——把当前 α/β 与**本人睁眼静息 60 秒的基线**相比，换算成 0–1 的指数，再用固定公式映射成画面参数：花开、天亮、雾散、水晶变清楚。患者看到的是"画面在不在状态"，不是"我的分数是多少"。

## 5. 可行性（Feasibility）

本阶段已完成工程验证，不是概念稿：

| 项 | 实测 / 现状 |
| --- | --- |
| 判定周期 | 4000 ms（4 秒窗，物理下限） |
| 分析耗时 | 1.0 ms |
| 传输延迟 | 中位 2.3 ms，95 分位 3.7 ms |
| 全链路 | 采集 → 判定 → 桥接 → Unity 画面 → 控制台 → 报告，本机跑通 |
| 硬件 | OpenBCI Cyton + Daisy（16 通道），经热点直连 |

**限制**：真实患者数据尚未接入；所有演示数字来自合成信号或健康成人自测，只用于验证链路自洽，不作为疗效结论。
