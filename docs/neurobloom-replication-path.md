# 复制路径（一页纸，照念能用）

> 一句话：**换一所医院，只需要 30 分钟装机 + 1 小时培训。**
> 因为采集硬件不绑品牌、算法跑在一台普通电脑上、数据不出院。

## 2. 换一所医院要什么（照这个清单点，一样都不多）

1. **设备三样**：16 通道采集板（基板 + 主采集板 + 从采集板）· 随设备的**干电极帽**（不打膏）· 一台能开浏览器的电脑（现有笔记本即可）。清洁用品只要酒精棉片 + 纸巾 + 一把小梳子。
2. **装机**：连板子的 WiFi 热点 `ExpandableEEGAP` → 控制台填 IP / 端口 / 板卡号（默认值就行）→ 点「连接设备」。
3. **培训 1 小时**：戴帽与看阻抗 15 分钟 → 点开始、看画面 15 分钟 → 结束后看报告 15 分钟 → 随访量表 15 分钟。
4. **第一天就能出东西**：一次会话报告 + 一页 PDF；做到第 8 次之后出趋势与风险提示。
5. **对接人只需要 1 个**：会戴帽、会点按钮的人，**不需要懂脑电**。

## 4. 为什么这条线抄得走（四条硬条件）

1. **不绑硬件**：换设备只改三个参数（板卡号 / IP / 端口），换品牌不重编译。
2. **不依赖专有数据**：阈值来自患者自己 60 秒静息，没有人群常模也能跑。
3. **不依赖网络**：采集、分析、语音合成都本地，内网断网也能跑，健康数据不出院。
4. **单人可操作**：一顶帽子 + 一台电脑 + 一个人。
