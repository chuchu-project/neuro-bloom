## 一、这是什么

**脑境 NeuroBloom**：卒中后居家康复期的脑健康管理闭环。
16 通道无线脑电 → 一人一基线的 α/β 判定 → VR 花园实时反馈 → 治疗师控制台五页 →
每周趋势与三级风险提示；随访量表（PHQ-2 / PHQ-9 / GAD-7）与脑电趋势合并判断。

## 三、怎么跑起来

```bash
bash setup/macos-dev-setup.sh
source .venv/bin/activate
cp .env.example .env      # 填书生 API Key（不填也能跑，只是不出引导语）
bash start.sh             # 起 bridge + 采集 + agent；bash stop.sh 停
```

浏览器打开 `http://127.0.0.1:8765/app.html`。

- 有采集板：设备页填 IP / 端口 / 板卡 → 检测 → 连接 → 训练页开始。
- 没有采集板：控制台点「演示（非脑电）」。演示数据全程带 `SIMULATED` 水印，关闭即回到空态。
