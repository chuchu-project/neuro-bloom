# 脑电设备上手（ExpandableEEG 16 通道）

按这份做，设备到手当天就能出数。全程只有一件事需要在 Windows 上做（改通信模式），其余 Mac 上完成。

## 零、最快路径：在控制台里连（不用终端）

1. 板子开机，电脑连 WiFi `ExpandableEEGAP`（密码 `abcd1234`）。
2. 打开控制台（桌面 NeuroBloom，或 `http://127.0.0.1:8899`）。
3. 点右上角 **「设备 · 未连接」** → 弹窗里确认 IP `192.168.4.1`、端口 `1112`、板卡 `16 通道`。
4. 先点 **「检测」**：显示"通了，XX ms 响应"再点 **「连接设备」**。
5. 状态变成 **「已连接」** 就成功了；点「开始演示」进 VR。

打不开或连不上时，弹窗底部会直接写原因：

| 提示 | 含义 | 怎么办 |
| --- | --- | --- |
| 连不上 192.168.4.1:1112 | 电脑没连上板子的热点，或板子没开机 | 连 `ExpandableEEGAP`，确认板子电源灯 |
| 端口通了，但脑电板握手失败 | 有东西占着端口 / 板子固件没就绪 | 关掉 OpenBCI GUI（它会独占 TCP），重启板子 |
| 一直"连接中" | 板子回了但没数据 | 看 `.data/logs/eeg.log` 最后 20 行 |

> 板子在线时，桥接启动会自动连（`DEVICE_AUTOCONNECT=1`，默认开），不用点任何按钮。
> 想强制用合成板：设 `DEVICE_AUTOCONNECT=0`，或在弹窗里点「用合成板」。

## 一、先搞清楚你手里是什么

| 部件 | 说明 |
| --- | --- |
| 基板（顶层板） | 充电 + 主控 + 通信（WiFi/蓝牙） |
| 主采集板（底层板） | 8 通道，芯片是 TI ADS1299 |
| 从采集板 | 每加一块 +8 通道。**你的是 16 通道 = 基板 + 主采集板 + 1 块从采集板** |

通道编号：底层 = 1–8，第二层 = 9–16。装卸从采集板**必须关机**，装好再开机，板子会自动识别通道数。

> 别买 32 通道：说明书明确写 32 通道需要替换 `boardController.dll` 且 BoardId 用 56，我们现有代码和驱动都不支持，也没必要。

## 二、接线（这一步错了后面全是噪声）

1. **单端接法**（脑电标准做法）：每块采集板的 `SRB` 接 `BUS_SRB`、`BIAS` 接 `BUS_BIAS`，让所有板共享参考。默认用 **SRB2**。
2. 电极插 **N 通道**（弯排排针的底层那一排）。引脚从右往左是 1→8，最左边是 `BIAS`，再往右是 `SRB2`、`SRB1`（说明书第 1–2 页）。
3. 参考电极：两个耳垂各放一个，分别接 **`SRB2`** 和 **`BIAS`**（说明书第 8 页眼电示例就是这么做的）。
4. `BIAS`（最左边那个引脚）不是接地，是偏置/右腿驱动，必须接，否则 50Hz 工频会盖住信号。

## 三、佩戴与阻抗（**干电极，不打膏**）

发货版配的是**干电极**：电极直接接触头皮，**不需要导电膏、不需要注射器**（说明书第 3 页）。

1. 戴之前：头发**吹干**、头皮干净；别涂护发素/发胶（说明书要求"保证头皮的干燥和卫生"）。
2. 戴帽：按发货版的地形图对位（说明书第 2–3 页的图 4 前面那张），**帽上电极插 N 通道**。
3. 测阻抗：OpenBCI GUI 里的 **Cyton Signal** 控件读每个通道阻抗（说明书第 3 页；32 通道不支持这功能）。
   - 阻抗越小越好；某几路明显偏高：**分开头发、压紧电极、擦干净电极**，没有"补膏"这一步。
4. **注意：长期佩戴会比较疼**（说明书原话）→ 单次训练控制在 8 分钟，疼就停、重新调整，别硬撑。
5. 我们的控制台不测阻抗，所以这一步只能用 OpenBCI GUI 做（见第五节）。

## 四、连上电脑（默认 WiFi AP 模式）

出厂就是 AP 模式，不用配置：

| 项 | 值 |
| --- | --- |
| WiFi 名 | `ExpandableEEGAP` |
| 密码 | `abcd1234` |
| 板子 IP | `192.168.4.1` |
| 端口 | `1112`（TCP） |

Mac 连上这个 WiFi 后，`ping 192.168.4.1` 通就说明链路好了。

注意：连上板子的 WiFi 后 Mac 就上不了外网了。两个办法：
- 用网线/USB 网卡上网（推荐，演示时大模型要联网）；
- 或者把板子改成 WiFi Client 模式接你现在的路由器（见下）。

### 改模式（只有这一步需要 Windows）

说明书里的 `Tools → ExpandableEEG_Config.exe` 是 Windows 程序，Mac 上跑不了。三种处理：

1. **最省事**：保持 AP 模式，Mac 用网线上网。演示现场不折腾配置。
2. 借一台 Windows 电脑，用配置工具改成 WiFi Client，接现场路由器，记下分配的 IP，然后：
   ```bash
   EEG_BOARD_ID=6 EEG_IP=<板子IP> EEG_IP_PORT=1112 bash dashboard/ensure-servers.sh
   ```
3. 蓝牙模式（续航最好、采样率最低）：Mac 需要 USB 串口驱动，`EEG_BOARD_ID=0 EEG_SERIAL_PORT=/dev/tty.usbserial-XXXX`。**不推荐**，演示时配对最容易出问题。

## 五、还需不需要 OpenBCI GUI？

**跑我们的系统不需要。** 我们用的是 BrainFlow，直接跟板子说话，绕开 GUI：

```
EEG_BOARD_ID=6          # Cyton + Daisy over WiFi = 16 通道
EEG_IP=192.168.4.1
EEG_IP_PORT=1112
EEG_IP_PROTOCOL=2       # TCP
```

（`eeg_service/main.py` 第 94–96 行有对照表：6=16 通道，5=8 通道，0=蓝牙/串口。）

**但第一次上手建议装一个 OpenBCI GUI**，只干三件我们不做的事：

1. 看阻抗（Cyton Signal）；
2. 确认 16 路都有信号（手指刷一下电极，看波形有没有反应）；
3. 看丢包率（Packetloss）——稳定性不行的时候，先怀疑 WiFi 而不是算法。

装完记得**关掉 GUI 再启动我们的服务**：GUI 会抢占板子的 TCP 连接，两个程序不能同时读。

## 七、采样率

- 8 通道：250 Hz
- 16 通道（Daisy）：每通道 125 Hz 左右，这是 OpenBCI 协议的固定行为，不是故障
- 代码会读板卡标称值；如果实测对不上，用 `EEG_SAMPLE_RATE=125` 覆盖，否则频率轴会整体偏移

125 Hz 对我们的算法够用：δ/θ/α/β/γ 里 γ 只到 60 Hz，Nyquist 62.5 Hz 刚好卡住上限，所以
γ 那一栏只看 30–45 Hz 的相对变化，不做绝对功率解释。

## 八、专注度（β/θ）能不能做？能，但有两个前提

**原理**：β（13–30 Hz）随注意投入上升，θ（4–8 Hz）随走神/困倦上升，β/θ 比值是注意力训练里最常用的指标之一。我们用的是「相对基线」而不是绝对阈值：先录 60 秒静息，之后的变化都跟自己的基线比。

**两个前提**：

1. **必须睁眼、看任务**。闭眼时 α 会淹没一切，β/θ 失去意义。训练时屏幕上要有明确目标（我们的水晶就是目标）。
2. **不能咬牙、皱眉、频繁眨眼**。咀嚼肌的电信号主要在 20–100 Hz，直接冒充 β。我们的通道质量检查会剔掉异常通道，但剔不掉"整段都在咬牙"。现场话术：`放松下巴，牙齿不要咬合`。

**通道要求**：前额—中央至少 4 路（Fp1/Fp2/F3/F4 或 Fz/Cz 附近），左右半球各 ≥3 路。16 通道满足；8 通道也满足但左右各只有 4 路，不对称指数会更抖。

## 九、常见故障对照

| 现象 | 先查什么 |
| --- | --- |
| 16 路里某几路一条直线 | 电极没插到底 / 该路缺膏 / 通道映射接错层（9–16 在第二层） |
| 全是 50 Hz 毛刺 | `BIAS` 或 `SRB2`（耳垂参考）没接、电极没贴到头皮（压头发上了）、电极脏 |
| 波形随眨眼大幅跳 | 正常（眼电），前额通道必然有；不要把这段当脑电特征 |
| 连不上 192.168.4.1 | 是否连的是 `ExpandableEEGAP`；GUI 是否还开着占着连接 |
| 数据一阵一阵断 | WiFi 干扰 → 换 5G 路由器 / 改 Client 模式 / 改蓝牙 |
| 通道数只有 8 | 从采集板没插好或开机时没装上；关机重装再开机 |
