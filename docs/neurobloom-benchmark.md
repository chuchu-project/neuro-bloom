# NeuroBloom 对标兴智杯获奖作品：差距与补齐

依据：`兴智杯AI+医疗赛题呈现与获奖作品分析.docx`（第三届赛题卡 + 两届一二等奖拆解 + 六段模板 + 五个扣分点 + 2026 六大方向竞争度）与一等奖「汪喵灵灵」的七维表格。

结论先说：**我们现在的技术完成度不低，但"成果叙事"只到二等奖水平，差的是复制路径、联合署名和落地数字。** 下面把差距拆成可执行的动作。

## 一、七维对标表（照「汪喵灵灵」的格式填我们）

|  |  |
| --- | --- |
| **赛题** | AI+医疗创新应用 · 脑机接口 VR 康复智能体（翔宇医疗命题） |
| **参赛单位** | 待定（建议：翔宇医疗 + 学校/学院 + 团队），署名顺序=分工：场景与临床 / 算法与工程 |
| **痛点呈现** | 我国每年新发脑卒中约 200–300 万例，约 1/3 出现卒中后抑郁；康复治疗师密度不足 4 人/10 万人口，单次训练需治疗师全程在场；市面脑机康复产品几乎只做肢体运动，情绪与注意力仍靠人工观察，训练依从性差。三个短句：**患者多、人手少、现有产品只看手脚不看情绪**。 |
| **方案呈现** | 16 通道**干电极**采集（8 通道 250 Hz；16 通道约 125 Hz）→ BrainFlow 直连 → 4 秒窗口做频带功率、左右半球不对称、β/θ 专注度 → Unity VR 场景实时改变（花、阳光、雾、水晶）→ 自动生成训练报告。**三层结构**：设备层（通用脑电帽，不绑定品牌）/ 算法层（一人一基线 + 双轴指标）/ 应用层（VR 场景 + 治疗师控制台 + 报告）。全程本地计算，数据不出院。 |
| **创新点呈现** | ① 一人一基线：先录 60 秒静息再比相对变化，跨被试不用调阈值（绝对阈值方案换个病人就失效）；② 左右半球不对称指数：16 路按 8+8 分半球，把"情绪偏侧化"变成可读数字；③ 放松/专注双轴：场景同时响应两条独立曲线，避免"越放松越无聊"；④ 闭环可量化：窗口凑齐到画面响应实测 2–3 ms（分析 0.7 ms、传输中位 1.6 ms）；⑤ 报告自动生成：有效率、趋势、α 占比直接落 HTML，治疗师 0 手工记录。 |
| **成效呈现** | 本机全链路已跑通：合成板 41 帧/40 秒会话自动出报告（有效通道 100%、放松占比 39%、α 占比 64.7%、趋势"后半段更不对称 +0.11"）；渲染两次逐像素差 0（画面可复现）；控制台 1440 宽无横向溢出。**真机数据待接入后补**（见"缺口"）。 |
| **可借鉴** | 一句话壁垒：**把情绪与注意力做成两条可解释、可复现的曲线，而不是一个玄学"专注值"**。小切口不怕，怕的是只有切口、没有复制路径——我们的复制路径是"同一套设备+算法，换科室（神经内科/康复科/老年科）只换训练场景"。 |

## 二、和一等奖差在哪（按文档的四条规律逐条对）

| 文档规律 | 一等奖做法 | 我们现在 | 差距等级 |
| --- | --- | --- | --- |
| 联合体署名 | 医院/研究所 + 企业 + 高校，四问答清楚（场景、数据、运维、付费） | 只有团队 + 命题方 | **高**：必须补翔宇医疗联合署名，写清"他们出场景与临床，我们出算法与工程" |
| 三组数字 | 痛点规模 / 技术参数 / 落地规模，缺一组故事就不完整 | 痛点是文献口径，技术参数齐，落地只有本机合成板 | **高**：真机 3–5 例 + 1 家科室试用，哪怕只是"已试点 N 人次" |
| 复制路径 | 一等奖都有第二条增长曲线（C 端→B 端 API→硬件） | 只有"一个 VR 场景" | **中**：写成"设备无关 + 场景可换 + 报告可对接 HIS"，复制到下一个科室只需换场景包 |
| 普惠 | 基层可部署、低成本、易复制 | 通用脑电帽 + 一台普通 PC，成本天然低，但没写出来 | **低**：一句话说清"整套硬件 < 一台进口康复机器人的 1/20" |
| 合规 | 至少一句数据脱敏/伦理/备案 | 措辞已避开"治疗"，数据本地，但没有书面合规段落 | **中**：补一段"数据不出院、伦理审查中、不作为诊断依据" |

### 还有两个文档点名的扣分项，我们正好踩了

1. **把"意向"写成"落地"**：现在只有本机合成板数据，答辩时**必须**说"合成板验证 + 真机待测"，不能说"已临床应用"。
2. **创新点写成功能清单**：我们五条已经都是"动作+结果"，但第 3 条（双轴）还缺一个数字，补"两条曲线相关性 r≈0（合成板）"更有说服力。

## 三、可以直接接进来的开源成品

原则：**只接成熟的、许可证干净的、能省我们自己维护成本的**，不为了"用了开源"而堆依赖。

| 组件 | 项目 | 热度/许可 | 用来做什么 | 现在 | 建议 |
| --- | --- | --- | --- | --- | --- |
| 脑电驱动 | [brainflow](https://github.com/brainflow-dev/brainflow) | 1.8k / MIT 系 | 统一 20+ 种板卡的采集接口 | **已接入** | 保持。它就是我们"设备无关"的底气 |
| 信号处理 | [MNE-Python](https://github.com/mne-tools/mne-python) | 3.6k / BSD-3 | 离线复核、伪迹标注、生成报告里的可信区间 | 未接入 | **建议接**：只用在离线报告，不进入实时链路，零风险 |
| 生理信号工具箱 | [NeuroKit2](https://github.com/neuropsychology/NeuroKit) | 2.4k / MIT | 以后加心率/皮电（多模态）时用 | 未接入 | 暂缓，等有第二模态再说 |
| 本地语音 | [piper](https://github.com/rhasspy/piper) | 11.3k / MIT | 向导语音离线合成，替代在线 TTS | 未接入 | **建议接**：断网也能说话，答辩现场不怕网络 |
| 语音识别 | [whisper.cpp](https://github.com/ggml-org/whisper.cpp) | 54.5k / MIT | 语音控制（"开始/停止/换个场景"） | 未接入 | 可选。演示加分，但会增加现场变量 |
| VR 交互 | [XR Interaction Toolkit 示例](https://github.com/Unity-Technologies/XR-Interaction-Toolkit-Examples) | 1.3k / Unity 许可 | Quest 上手柄/手势交互 | 未接入 | 上 Quest 时再接，PC 版不需要 |
| 脑电帽固件生态 | OpenBCI GUI / Cyton 协议 | 官方开源 | 首次阻抗检查、丢包排查 | 工具用 | 只用一次，不进产品 |

一句话：**BrainFlow 已经让我们"什么帽子都能接"，MNE + piper 是最值得补的两块**（一个让报告更可信，一个让演示不依赖网络）。

## 五、答辩口径（照念版）

> 我们做的是卒中后情绪—注意力辅助训练。设备用通用 16 通道脑电帽，算法先给每位患者录 60 秒静息做基线，之后所有指标都跟自己的基线比，所以换人不用调参数。
>
> 场景里有两个独立维度：放松度决定花园长成什么样，专注度决定水晶的清晰度。判定每 4 秒一次，窗口一满到画面响应 2 到 3 毫秒，瓶颈不在软件。
>
> 训练结束自动生成报告，包含有效通道比例、放松时间占比、左右半球不对称趋势，治疗师不用手写记录。
>
> 目前完成的是合成信号下的全链路验证，真实患者数据在接入中——我们不会把"验证"说成"临床"。
